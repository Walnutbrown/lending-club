# Lending Club 1st-stage study

This archive preserves the earliest Lending Club analysis that preceded the structured feature-engineering and model-comparison pipeline in the parent repository.

## Curated order

1. `01_initial_data_definition.ipynb`
2. `02_default_labeling.ipynb`
3. `03_baseline_model.ipynb`
4. `04_feature_selection.ipynb`
5. `05_information_set_review.ipynb`

The archive demonstrates the progression from defining `default`, to selecting an information set, to a baseline train/validation/test analysis and risk-adjusted-return summary.

The full local `lendingclub.csv` export was intentionally excluded because it is approximately 2 GB. Small samples, the data dictionary, helper code, and the original summary are included.
